# 环境配置

## 1. 固定工作目录

```bash
cd /path/to/YOLO_Annotation_Pipeline
```

推荐 Linux 本地运行。桌面 App 使用系统 Python/PyQt5，算法由各自 Conda 环境执行。

## 2. Conda 环境

| 环境 | 默认 Python | 用途 |
|---|---|---|
| `orbbec` | `~/miniforge3/envs/orbbec/bin/python` | Gemini 336L RGB-D 采集 |
| `yolo11` | `~/miniforge3/envs/yolo11/bin/python` | YOLO11、SAM2、实时识别 |
| `foundationpose` | `~/miniforge3/envs/foundationpose/bin/python` | FoundationPose、PyTorch3D、NVDiffRast |

环境定义：

```text
environments/environment_orbbec_ubuntu24.yml
environments/environment_foundationpose_ubuntu24.yml
```

路径覆盖变量：

```text
ATEC_ORBBEC_PY   Orbbec 环境 Python
ATEC_FP_PY       FoundationPose 环境 Python
ATEC_YOLO_PY     YOLO11/SAM2 环境 Python
```

实时识别启动器还支持：

```text
ATEC_YOLO_MODEL
ATEC_YOLO_SOURCE
ATEC_YOLO_CONF
ATEC_YOLO_IMGSZ
ATEC_YOLO_DEVICE
```

## 3. 环境检查

```bash
./scripts/atec-pipeline doctor
./scripts/atec-pipeline doctor --deep
./scripts/check_all_environments.sh
./scripts/check_orbbec.sh
./scripts/check_foundationpose.sh
./scripts/verify_local_assets.sh
```

## 4. 第三方源码和模型

第三方源码统一放在：

```text
third_party/FoundationPose
third_party/OrbbecSDK_v2
third_party/pyorbbecsdk
third_party/BundleSDF
third_party/nvdiffrast
third_party/pytorch3d
```

检查或安装：

```bash
./scripts/bootstrap_third_party.sh --check
./scripts/bootstrap_third_party.sh --install
```

第三方源码、模型权重、真实数据和训练输出默认不提交 Git。模型按 `models/README.md` 放置，然后运行：

```bash
./scripts/verify_local_assets.sh
```

## 5. 设备与窗口排错

Orbbec：

```bash
lsusb
./scripts/check_orbbec.sh
~/miniforge3/envs/orbbec/bin/python tools/orbbec_usb_diagnostics.py
```

外接摄像头：

```bash
ls -l /dev/video*
```

如果 App 从 Conda、ROS、Snap 终端启动后发生 Qt/GTK 冲突，应仍通过：

```bash
./scripts/atec-app
```

启动器会清理会污染系统 PyQt5 的动态库和 GTK 环境变量。

## 6. 技术边界

- SAM2 是视频 Mask 传播主线。
- FoundationPose 只用于具有可靠正确尺度 CAD/Mesh 的刚体 6D 辅助，不是 YOLO 标签转换器。
- 西瓜皮、餐盒和纸袋等可变形目标优先使用 SAM2 与人工 Review。
- Orbbec 负责 RGB-D 采集；普通外接 RGB 摄像头可用于低复杂度实时识别测试。
