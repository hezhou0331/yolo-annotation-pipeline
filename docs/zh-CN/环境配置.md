# 环境配置

## Conda环境

```text
foundationpose  FoundationPose、PyTorch3D、NVDiffRast、Warp、mycpp
yolo11          Ultralytics YOLO11、SAM2
orbbec          PyOrbbecSDK、OpenCV和RGB-D采集工具
```

环境定义：

```text
environments/environment_foundationpose_ubuntu24.yml
environments/environment_orbbec_ubuntu24.yml
```

## 环境检查

```bash
./scripts/atec-pipeline doctor
./scripts/atec-pipeline doctor --deep
./scripts/check_foundationpose.sh
./scripts/check_orbbec.sh
./scripts/verify_local_assets.sh
```

第三方源码默认位置为`third_party/`。如新电脑缺失，运行：

```bash
./scripts/bootstrap_third_party.sh --install
```

模型不会从Git恢复，按`models/README.md`放置后运行SHA256校验。

## 路径覆盖

```text
ATEC_ORBBEC_PY  Orbbec环境Python
ATEC_FP_PY      FoundationPose环境Python
ATEC_YOLO_PY    YOLO11/SAM2环境Python
```

Manifest中的`project.foundationpose_dir`可以覆盖默认的`third_party/FoundationPose`路径。
