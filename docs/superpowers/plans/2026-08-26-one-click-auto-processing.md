# 一键自动处理所有场景：实施计划

1. 新增纯状态模块，负责完整性预检、保守修复、场景动作规划、Manifest 初始化参数验证和原子报告。
2. 先用 CPU/临时目录测试覆盖安全孤立文件、不可修复缺帧、缺关键 Mask、已完成跳过、待传播/失败重跑、Manifest 自动补建、损坏拦截、可证明字段备份修复和报告汇总。
3. 为 GUI 增加独立批处理 `QProcess`、总体进度、当前场景/阶段、计数、失败原因和停止按钮。
4. 批处理按 `init -> segment -> run` 动态复查文件状态；任一场失败记录后继续。
5. 仅锁定当前批处理场景，允许其他场景继续选择、标注和 Review；阻止采集、训练、实时识别等资源冲突操作。
6. 运行定向测试、GUI offscreen 测试及相关完整回归，检查 Git diff 不包含用户数据变更。
7. 对 FailedToStart、关闭窗口和整进程组停止增加回归测试，防止失败信号串场或遗留后台 SAM2/GPU 进程。
